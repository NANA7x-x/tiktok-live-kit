# TikTok LIVE キット v4

ギフトの「1個あたりのコイン数」で、なな が何をするかが**必ず**決まる配信オーバーレイ。
運の要素（抽選・スロット・ルーレット）と景品はありません。お返しはぜんぶ配信の中で演じるもの（語尾・一人称・手元カメラ・ピアノなど）です。

## 起動（ワンクリック）
**最初の1回だけ**：キットのフォルダにある **`desktop_icon.vbs`** をダブルクリック → デスクトップに **「NANA LIVE」** アイコンができる

**あとは毎回**：デスクトップの **「NANA LIVE」をダブルクリックするだけ**
- サーバーが動いていなければ起動して、リモコンを開く（初回は必要な部品の `npm install` も自動）
- もう動いていれば、リモコンだけ開く
- サーバーの黒い画面はタスクバーに最小化で残ります。閉じるとサーバーが止まります

PCをつけたら勝手にサーバーも起動してほしい場合は `自動起動.md` を見てください（`autostart_setup.vbs` でも「NANA LIVE」アイコンが作られます）。

アイコンがセキュリティに止められた場合：デスクトップで右クリック →「新規作成」→「ショートカット」→ 項目の場所に
`"C:\Program Files\nodejs\node.exe" "（キットの場所）\start.js"` を貼り付け → 名前を「NANA LIVE」にして完了。

手で起動する場合（今まで通り）：フォルダのアドレスバーに `cmd` → `node start.js`（または `node server.js @7x_x7x_x7x_x7`）

TikTokのユーザー名を変えたいときは、キットのフォルダに `tiktok_user.txt` を作って1行目に `@ユーザー名` を書く（無ければ `@7x_x7x_x7x_x7`）。

## OBSに入れるもの（上から順に）
| 順番 | ブラウザソースのURL | 中身 |
|---|---|---|
| 1（いちばん上） | `http://localhost:21213/overlay.html` | 情報と演出（ギフト表・NOW・TEAM・CHAIN・カットイン） |
| 2 | `http://localhost:21213/front.html` | ふんわりエフェクト手前（大きなボケ・光漏れ・きらめき）。ブレンドモードを「スクリーン」にするとより自然 |
| 3 | （VTube Studio などのアバター） | |
| 4 | `http://localhost:21213/back.html` | ふんわりエフェクト奥（小さなボケ・虹の光） |

- どれも幅 1080 × 高さ 1920 で追加
- 前の版の `transparent.html` のURLもそのまま使えます（中身は overlay.html と同じ）
- 効果音は overlay.html から鳴ります（OBSで「音声をOBSで制御する」にチェック）

## リモコン
`http://localhost:21213/remote.html`

- **⏱ 発動中・リクエスト**：今の変身と残り時間、ピアノのリクエスト待ち（弾いたら「済」）
- **🖼 配信内容・モード**：上に出すラベル（「※ ピアノ歌枠です」など）、アバター中心／ゲーム配信モード、ふんわりエフェクト
- **🎁 テスト送信**：コイン数ごとにテスト。DiscordやVRChatには流れません
- **🎨 見た目**：配色プリセット（ネオン・パステル・ラベンダー・さくら・サイバー・ゴールド・モノクロ）、色の個別変更、見出し／本文フォント（手書き系あり。PCに入っているフォント名の直接指定も可）、枠・形・板の濃さ
- **🪙 ギフト表**：何コインから何が起きるかを編集
- **🎹 みんなで達成ゲージ**：達成で何をするか、満タンの量
- **📡 接続・音・連携**：TikTok接続（自動／手動）、効果音、CHAINの秒数、VRChatテスト

## 初期のギフト表
| コイン（1個あたり） | 起きること |
|---|---|
| 1〜 | お名前コール |
| 10〜 | 語尾「にゃん」3分 |
| 30〜 | 一人称「俺」固定 5分 |
| 50〜 | ボイスエフェクト（ロボ声）2分 ※音声の経路をOBSにまとめてから |
| 100〜 | スクワット10回 |
| 199〜 | 手元カメラON 10分 |
| 500〜 | ピアノ サビだけ1曲 |
| 1,000〜 | ピアノ フルで1曲 |
| 5,000〜 | ピアノ弾き語り1曲 |

- 同じ変身中に同じ段のギフトが来たら時間が延長されます。別の変身は順番待ち（声・カメラ・ボイスは別枠なので同時に動く）
- 連投（×10など）は個数分まとめて数えます

## 連携（任意・設定しなければOFF）
- Discord：`DISCORD連携.md`
- VRChat：`VRC連携.md`
- 自動起動：`自動起動.md`

## 保存されるもの
- `kit_state.json` … ギフト表・見た目・発動中・リクエスト・ゲージ（サーバーが自動保存。OBSを開き直しても消えない）
- `highlights_YYYY-MM-DD.txt` … ハイライト（切り抜き候補）
- `stream_reports.txt` … 配信レポート（本人用）

## 注意
- サーバーは「このフォルダの中身」を配っています。別のフォルダのファイルを差し替えても画面は変わりません
- サーバーは常に1つだけ起動すること（黒画面が複数あったら全部閉じてから起動し直す）
