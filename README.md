# TikTok LIVE キット v3（完全版）

## セットアップ
1. このフォルダをデスクトップに置く
2. フォルダのアドレスバーに `cmd` と打って Enter（黒画面）
   ※ start.bat が Smart App Control に止められたら、この手入力方式でOK
3. 黒画面で順番に：
   ```
   npm install
   node server.js @7x_x7x_x7x_x7
   ```
4. 黒画面に「起動: http://localhost:21213/」「TikTok LIVE接続成功」と出ればOK。黒画面は閉じない

## 開くページ
- リモコン: http://localhost:21213/remote.html
- OBS用（透過・操作パネルなし）: http://localhost:21213/transparent.html?clean=1
- OBS用（通常・操作パネルなし）: http://localhost:21213/?clean=1

## Discord連携（任意）
- 配信終了時の「出席簿まとめ」と、TikTok／YouTubeの配信開始告知を、Discordに自動投稿できます
- 配信終了時には「ハイライトまとめ（切り抜き候補）」も告知用チャンネルへ投稿されます（大当たりや伝説誕生の瞬間を、配信開始からの経過時間つきで一覧化）
- ハイライトは discord_webhook.txt が無くても、キットのフォルダの `highlights_YYYY-MM-DD.txt` に記録されます
- 設定方法は同梱の **DISCORD連携.md** を見てください（ウェブフックURLを discord_webhook.txt に貼るだけ）
- 設定しなければ今まで通り動きます（連携はOFFのまま）

## VRChat連携（任意）
- ギフト到着・大当たり（確変/777/超大当たり）・効果当選を、VRChatのチャットボックスに自動で流せます（金額は流れません）
- 設定方法は同梱の **VRC連携.md** を見てください（vrc_osc.txt の1行目を on にしてサーバー再起動、VRChat側でOSC有効化）
- リモコンの「VRCテスト送信」ボタンで動作確認できます
- 設定しなければ今まで通り動きます（連携はOFFのまま）

## いいね連携
- 配信中の「いいね」（画面タップ）の合計数が節目に達すると、自動で回転数が追加されます（ルーレットは回りません）
  - **500いいねごと → +10回転**／**1,000の倍数 → +30回転**（ボーナス込み）
- 画面下部の「❤️ いいねゲージ」で、現在の合計いいね数と次の節目までの進み具合が見えます（レイアウト編集で移動できます）
- 節目の管理はサーバー（黒画面）側で行うので、画面を再読み込みしても同じ節目が2回払われることはありません
- サーバーを途中で起動し直しても、同じ配信なら続きから数えます（状態は like_state.json に自動保存）。新しい配信では自動でリセットされます

## 新機能（バースデー／MVP／図鑑）
- **🎂 バースデーモード**：リモコンか画面の操作バーのボタンでON/OFF。画面が誕生日仕様の飾りになり、ギフトの紙吹雪とお祝いコールが増えます（状態は保存されます）
- **🏆 MVP発表**：リモコンか操作バーのボタンで、その配信で一番コインを投げた方を画面中央で発表します
- **📖 ギフト図鑑**：その日もらったギフトの種類を集めるパネル（12種のコンプリートで特別コール）。レイアウト編集で移動できます

## 注意
- サーバーは「このフォルダの中身」を配っています。別のフォルダのファイルを差し替えても画面は変わりません
- 古いキットのフォルダは消してOK（この v3 だけ使う）
