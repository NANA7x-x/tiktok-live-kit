🫧 画面エフェクト・前エフェクト・ハプニング
背景ムービー（200コイン）：キットの「背景」フォルダに 動画（mp4 / webm / mov）か 画像（jpg / png / gif / webp）を入れるだけで、順番に追加されます（15秒くらいで自動で反映）。ファイル名がそのまま名前になります（例：夜の海.mp4 →「背景ムービー：夜の海」）。動画は音なし・くり返し再生、画像はゆっくりズームします。
前エフェクト（88コイン）：アバターの前に重なる飾り。レアカード／金の縁取り／メタル／桜ふる／雪ふる／水の中／炭酸のコップ。ハプニング（400コイン）：川に流される／海に出ていく／化け物に連れ去られる／UFOにさらわれる／網でつかまる／瓶づめ／投獄／いきなり踊らされる／巨人の料理にされる。「🎬 OBS 連携」をすると配信画面ごと動きます（つないでいないときは、VTube Studio 連携でアバターだけ動きます）。ゆらめき・背景ムービー・前エフェクトは、別の段のギフトが来てもその場で切り替わって時間が足されます。
ゆらめき（100コイン）：下の「ギフト表」の 100 の段の「順番リスト」に色を足せます。使える色の名前：ピンク／ラベンダー／ミント／水色／ゴールド／ピーチ／ブルー／ローズ／ホワイト／レッド／グリーン／オレンジ／パープル／シアン。好きな色にしたいときは さくら色#ffb7d5 のように名前のうしろに色コードをつけます（画面には「さくら色」とだけ出ます）。

🎬 OBS 連携（ハプニングで配信画面ごと動かす）
ハプニング（400コイン）で、アバターが流されたり、瓶につめられたり、食べられたりします。
① OBS の「ツール → WebSocketサーバー設定」で「WebSocketサーバーを有効にする」をON（パスワードを使うなら下に入れる）
② ここを ON にして「接続OK」になったら、ふだんの配信シーンを表示した状態で「OBS を準備する」を押す
③ 「アバターのソース」で VTube Studio などアバターを映しているソースを選んで、もう一度「OBS を準備する」を押す
→ ハプニングではアバターだけが動きます（画面全体は動かないので酔いにくい）。まわりの絵はアバターのすぐ奥と手前に出ます。仮想カメラはそのままでOK。

🧸 VTube Studio 連携
連携-
VTube Studio の「設定 → VTube Studio API を起動」をONにしておく（ポートは普通 8001）。ここをONにすると、初回だけ VTS の画面に「NANA LIVE kit を許可しますか？」が出るので「許可」を押す。
テスト
このモデルのホットキー押すとテスト。ギフト表の連携欄には「vts:hotkey:名前」と書く
ギフト表の「連携」欄の書き方：
・動き（その場だけ）… vts:jump ／ vts:spin ／ vts:shake ／ vts:shrink ／ vts:grow ／ vts:fly
・色 … vts:rainbow ／ vts:red ／ vts:blue ／ vts:gold ／ vts:pink（変身の段なら変身中ずっと、それ以外は9秒）
・ホットキー … vts:hotkey:猫耳（変身の段なら終わるときにもう一度押して戻す。「@20」を付けると20秒後に押し直す）
・VRChat … vrc:パラメーター名=true（変身中ずっと／それ以外は9秒で戻す。数字も可）
・いくつも書くときはスペースで区切る（例：vts:rainbow vts:spin）
