# VTube Studio 連携

ギフトに合わせて、VTube Studio のアバターを動かしたり、色を変えたり、ホットキー（表情・Visual Effects など）を押したりできます。**新しく素材を作らなくても**、動きと色はすぐ使えます。

## 最初の1回だけ
1. VTube Studio を起動して、「設定（歯車）」→ **「VTube Studio API を起動」をON**（ポートは普通 8001 のまま）
2. リモコンの「🧸 VTube Studio 連携」で **ON** を押す
3. VTube Studio の画面に「NANA LIVE kit を許可しますか？」が出るので **「許可」** を押す
4. リモコンの表示が「接続OK」になれば完了（次からは自動でつながります）

## ギフト表の「連携」欄の書き方
| 書き方 | 何が起きるか |
|---|---|
| `vts:jump` | ぴょんぴょん跳ねる |
| `vts:spin` | くるっと1回転 |
| `vts:shake` | ぶるぶる震える |
| `vts:shrink` / `vts:grow` | ちっちゃくなる／おおきくなる（6秒で戻る） |
| `vts:fly` | 画面の外へ吹っ飛んで、反対側から戻ってくる |
| `vts:rainbow` / `vts:red` / `vts:blue` / `vts:gold` / `vts:pink` | アバターの色（変身の段なら変身中ずっと、それ以外は9秒） |
| `vts:hotkey:名前` | VTSのホットキーを押す。変身の段なら、終わるときにもう一度押して戻す |
| `…@20` | 20秒後に戻す（例 `vts:hotkey:猫耳@20`） |

- いくつも書くときはスペースで区切る（例 `vts:rainbow vts:spin`）
- ホットキーの名前は、リモコンの「このモデルのホットキー」に一覧で出ます（押すとテスト）
- 表情をホットキーにしておけば、「語尾にゃん中は猫耳」のような連動ができます
- 初期のギフト表では：スクワット＝ぴょん、ピアノ フル＝虹色＋1回転、弾き語り＝虹色＋おおきく。早口言葉の成功で1回転、失敗でぶるぶる

## うまくいかないとき
- 「接続中…」のまま → VTube Studio が起動しているか、API がONか、ポート番号が同じか
- 「拒否されました」 → リモコンの「再接続」を押して、VTSで「許可」を押す
- 動きがずれて戻らない → VTSでモデルの位置をリセット（動きは必ず戻す作りですが、途中でVTSを操作するとずれることがあります）

## VRChat のアバター（まだアバターがなくても大丈夫）
連携欄に `vrc:パラメーター名=true` と書くと、VRChat のアバターのパラメーター（メニューのトグル）を OSC で動かします。
- 例：`vrc:Ears=true`（猫耳ON。変身中ずっと／それ以外は9秒で戻る）
- `設定/vrc_osc.txt` の1行目を `on` にしておく必要があります（`説明書/VRC連携.md`）
- パラメーター名はアバターごとに違います。アバターを用意したら、その名前を書くだけで使えます
