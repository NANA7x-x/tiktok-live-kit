# 更新のしかた（本人用メモ）

このリポジトリがキットの正本。Claude がここに新しい版を push する。

## 初回だけ
1. GitHub Desktop でこのリポジトリを Clone する
2. Discord連携を使うなら、`discord_webhook.txt` を **「設定」フォルダ** に入れる
3. キットのフォルダの **`はじめに_アイコンを作る.vbs`** をダブルクリック → デスクトップに「NANA LIVE」ができる
   （必要な部品の `npm install` は、アイコンを初めて押したときに自動でやります）

## 起動
デスクトップの **「NANA LIVE」** をダブルクリック（サーバー起動＋リモコンが開く。動いていればリモコンだけ開く）

## 更新があったら（自動化済み）
1. GitHub Desktop で **Fetch origin → Pull** を押すだけ

- `app/server.js` が更新された場合、起動中のサーバーが自動で再起動する（新しい黒画面が開く）。
- 画面側のファイル（`app/overlay.html`）が更新された場合、OBS のオーバーレイが自動で読み直すので、OBS の「キャッシュを更新」も不要。
- リモコンだけは、更新後にブラウザで F5 を1回押して。

※ サーバーは常に1つだけ起動すること（古いのが残っていると新しい信号が届かない）。

## フォルダ整理の版（v4.1）に上げるときだけ（1回）
- 起動中のサーバー（黒い画面）を全部閉じてから Pull する
- `discord_webhook.txt` をキットのフォルダ直下から **「設定」フォルダ** へ移す（直下のままでも動きます）
- 自動起動を使っていた場合は、**`ツール/自動起動をONにする.vbs`** をもう一度ダブルクリック（場所が変わったため）
- デスクトップの古い「TikTokRemote」は消してOK（「NANA LIVE」が代わり）
- キットのフォルダ直下に残っている前の版のファイル（`layout.json` `visibility.json` `simple.json` `like_state.json` `tokudai_log.json` `perks.json` `sounds.json` `style.json` `screenfx.json` `sounds` フォルダなど）は、もう使わないので消してOK
